# Nathan — Personal Website V1

One-page personal portfolio for Nguyễn Minh Nguyên (Nathan).

## Stack
- Astro
- Vanilla CSS
- Vanilla JavaScript
- Be Vietnam Pro
- GitHub Pages via GitHub Actions

## Run locally

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```

## Before deploying
1. Open `astro.config.mjs`.
2. Replace `https://YOUR-USERNAME.github.io` with your GitHub Pages URL.
3. If the repository is not named `<username>.github.io`, set `base: '/repository-name'`.
4. Add your images to:
   - `public/images/profile/profile.jpg`
   - `public/images/projects/`
   - `public/images/life/`
5. Enable GitHub Pages using **GitHub Actions** as the source.

## Current image placeholders
The site intentionally works even before real images are added. Missing image files will leave the designed placeholder layer visible; add the real files later.
